# 📊 Mercado Nova Sales & Delivery Dashboard

An interactive **Excel Data Analysis Dashboard** developed to analyze Mercado Nova's order, revenue, and delivery performance across 2017 and 2018.

The project was developed as part of the training under **iCareer & EraaSoft (#DigitEra)**.

---

## 📌 Project Overview

The dataset consisted of multiple monthly order files covering **2017 and 2018**.

The main goal of this project was to combine, clean, transform, and analyze the data and build an interactive dashboard that provides insights into:

- Order performance
- Revenue and GMV
- Customer locations
- Delivery performance
- Review scores
- Monthly trends

---

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- **Power Query**
- **Pivot Tables**
- **Measures**
- **Excel Charts**
- **Slicers**
- **VBA**
- **ActiveX Controls**

---

## 🔄 Data Preparation

### Power Query

Power Query was used to:

1. Import the monthly order files.
2. Combine the files from 2017 and 2018 into one table.
3. Clean and transform the data.
4. Prepare the dataset for analysis and visualization.

---

## 📊 Dashboard Features

The dashboard includes several KPIs and visualizations.

### Key Performance Indicators

- **Total Orders**
- **Average Review Score**
- **GMV**
- **Revenue**
- **Average Order Value (AOV)**
- **Late Delivery Rate**

### Visualizations

- Total Orders by City
- Total Revenue by State
- Order Status Distribution
- Late Delivery Rate by Month
- Total Revenue by Month

### Interactive Filters

The dashboard includes slicers for:

- Customer State
- Customer City
- Order Delivery Status
- Year
- Month

In addition, custom **search boxes using ActiveX + VBA** were implemented for searching states and cities directly from the dashboard.
